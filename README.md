# Hospital Management System

A simple console-based **Hospital Management System** built in Python using CSV files for data storage.

## Features
-  Add new Patient records
-  View all Patient records
-  Search Patient by ID
-  Delete Patient record
-  Generate Patient Bill (Doctor fees + Medicine charges)
-  View all generated Bills

## Technologies Used
- Python 3
- CSV (for persistent storage)
- No external libraries required (only built-in `csv` and `os`)

## How to Run
1. Clone the repository
2. Run the script:
   ```bash
   hospital-management-system.py
